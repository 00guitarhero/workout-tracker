# Python Workout Tracker

A console-based workout tracker built with Python and SQLite.

## Features

- Add exercises with weight, sets, and reps
- View current workout exercises
- Edit and remove exercises
- Calculate total workout volume
- View workout history
- Store workout data in an SQLite database

## Technologies

- Python
- SQLite
- SQL

## How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run:

   ```bash
   python3 workout_tracker_sqlite.py
   ```

5. Follow the menu prompts to manage your workouts.

The program creates its SQLite database when it runs.

## Purpose

This project was built to practice Python programming, SQL queries, and database management.
